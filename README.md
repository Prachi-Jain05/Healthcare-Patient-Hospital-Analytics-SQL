# Healthcare Patient & Hospital Analytics Using SQL

## Tools Used
- MySQL

## Project Overview
Analyzed 55,500 healthcare records to identify patient trends, hospital performance, doctor rankings, insurance coverage patterns, and revenue drivers.

## SQL Concepts Used
- GROUP BY
- ORDER BY
- CASE WHEN
- Subqueries
- RANK()
- DENSE_RANK()

## Business Questions Solved
- Most common medical conditions
- Revenue by hospital
- Revenue by insurance provider
- Doctor performance analysis
- Age group analysis
- Above-average billing analysis

## Key Insights
- Identified top revenue-generating hospitals and doctors.
- Analyzed patient demographics and age-group trends.
- Evaluated insurance provider contributions.
- Used advanced SQL techniques to generate business insights.
